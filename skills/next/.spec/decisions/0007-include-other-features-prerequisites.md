# Decision 0007: Include other Features' prerequisites

**Date:** 2026-10-14
**Decided by:** the repository maintainer, in Hooked decision 0007 (2026-10-13).

## The call

A focused answer includes each required prerequisite that another Feature owns,
naming its owning Feature and what it advances in the requested scope.

## Why

Ported from Hooked decision 0007. A focused answer must give a path through all
the work needed to finish its Features.

## Rejected

Restricting recommendations to the requested Features and reporting outside
prerequisites only as blockers. The answer stays narrower, but has no actionable
path when the next step belongs to another Feature. The chosen call broadens the
work displayed.

## Affects

B-003.

## Reversal

None.
