# Decision 0012: Isolate incomplete delivery evidence

**Date:** 2026-10-14
**Decided by:** the repository maintainer, in Hooked decision 0012 (2026-10-13).

## The call

When a link or an item's delivery state is missing, ambiguous or cannot be read,
the affected start is withheld and the gap is named. Verified independent work is
still ranked and offered. When no delivery state can be read, the answer is
diagnostics with no start. Whether a mirrored status may stand in for an
unreadable tracker is not decided here (OQ-1).

## Why

Ported from Hooked decision 0012. Incomplete records must neither hide
independent verified work nor create false readiness.

## Rejected

Failing the whole report until every record is valid. Simpler, but discards the
verified choices; the chosen call gives an answer that is explicitly incomplete.

## Affects

B-029, B-030, B-032, OQ-1.

## Reversal

None.
