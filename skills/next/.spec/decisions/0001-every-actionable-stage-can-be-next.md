# Decision 0001: Every actionable stage can be next

**Date:** 2026-10-14
**Decided by:** the repository maintainer, in Hooked decision 0001 (2026-10-13).

## The call

Specification, decomposition, design, investigation and implementation work can
each be recommended as next. Each recommendation states which stage is next.
Readiness for one stage does not imply readiness for a later one.

## Why

Ported from Hooked decision 0001. An implementation-only answer hides the work
needed to reach implementation.

## Rejected

An implementation-only view. It needs no readiness rule per stage, but leaves the
agreement, decomposition and design work that precede implementation outside the
answer. The chosen call costs a readiness rule for each stage (decision 0010).

## Affects

B-009, B-010, B-012.

## Reversal

None.
