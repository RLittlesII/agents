# Decision 0014: Standalone work stays visible

**Date:** 2026-10-14
**Decided by:** the repository maintainer, in Hooked decision 0014 (2026-10-13).

## The call

Actionable standalone work, such as a bug, a chore or a spike outside any
Feature, stays visible in a repository-wide answer without an invented completion
score, and needs no Feature specification to appear. The companion directs how
it is shown. A focused answer includes it only when it is a required
prerequisite.

## Why

Ported from Hooked decision 0014. Item-first work is real work without
artificial Feature membership.

## Rejected

- Showing only Feature-linked work. It orders everything one way, but hides
  legitimate standalone work or forces it into a Feature. The chosen call gives
  standalone work no common ordering against Feature work.
- Fixing a separate report section for it, as Hooked did. Where it is shown is
  the companion's.

## Affects

B-038, B-003.

## Reversal

None.
